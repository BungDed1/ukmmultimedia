Matematika & Kalkulasi

MATH
Rumus dasar hitung-menghitung untuk laporan keuangan, analisis data, dan kalkulasi bisnis.
#001
SUM
=SUM(angka1;angka2; ...)
Menjumlahkan semua angka dalam range atau daftar nilai.
Contoh: =SUM(B2:B20) — total penjualan bulan ini
#002
SUMIF
=SUMIF(range;kriteria;sum_range)
Menjumlahkan nilai yang memenuhi satu syarat/kriteria tertentu.
Contoh: =SUMIF(C2:C100;"Laptop";D2:D100)
#003
SUMIFS
=SUMIFS(sum_range;range1;krit1; ...)
Menjumlahkan nilai berdasarkan banyak syarat sekaligus.
Contoh: =SUMIFS(D2:D100;C2:C100;"Laptop";E2:E100;"Jakarta")
#004
AVERAGE
=AVERAGE(angka1;angka2; ...)
Menghitung rata-rata dari sekumpulan angka.
Contoh: =AVERAGE(C2:C30) — rata-rata nilai ujian
#005
AVERAGEIF
=AVERAGEIF(range;kriteria;avg_range)
Rata-rata nilai yang memenuhi satu kondisi tertentu.
Contoh: =AVERAGEIF(B2:B50;"Lulus";C2:C50)
#006
AVERAGEIFS
=AVERAGEIFS(avg_range;range1;krit1; ...)
Rata-rata berdasarkan banyak kondisi.
Contoh: =AVERAGEIFS(D2:D50;B2:B50;"A";C2:C50;"TI")
#007
COUNT
=COUNT(value1;value2; ...)
Menghitung jumlah sel yang berisi angka.
Contoh: =COUNT(B2:B100) — berapa data angka ada
#008
COUNTA
=COUNTA(value1;value2; ...)
Menghitung semua sel yang tidak kosong (termasuk teks).
Contoh: =COUNTA(A2:A200) — jumlah baris terisi
#009
COUNTIF
=COUNTIF(range;kriteria)
Menghitung sel yang memenuhi satu syarat.
Contoh: =COUNTIF(C2:C100;"Aktif")
#010
COUNTIFS
=COUNTIFS(range1;krit1;range2;krit2)
Menghitung sel yang memenuhi banyak syarat.
Contoh: =COUNTIFS(B:B;"Laki-laki";C:C;"S1")
#011
PRODUCT
=PRODUCT(angka1;angka2; ...)
Mengalikan semua angka dalam range (perkalian massal).
Contoh: =PRODUCT(B2:B5)
#012
MOD
=MOD(angka;pembagi)
Sisa hasil bagi (modulus). Berguna cek genap/ganjil.
Contoh: =MOD(A2;2) → 0=genap, 1=ganjil
#013
ROUND
=ROUND(angka;desimal)
Membulatkan angka ke sejumlah digit desimal.
Contoh: =ROUND(3.1415;2) → 3.14
#014
ROUNDUP / ROUNDDOWN
=ROUNDUP(angka;desimal)
Bulatkan selalu ke atas atau selalu ke bawah.
Contoh: =ROUNDUP(2.3;0) → 3
#015
ABS
=ABS(angka)
Mengembalikan nilai absolut (tanpa tanda minus).
Contoh: =ABS(-500) → 500
#016
POWER / ^
=POWER(basis;eksponen)
Menghitung hasil perpangkatan (basis^eksponen).
Contoh: =POWER(2;10) → 1024
#017
SQRT
=SQRT(angka)
Menghitung akar kuadrat dari sebuah angka.
Contoh: =SQRT(144) → 12
#018
INT
=INT(angka)
Membulatkan angka ke bilangan bulat terdekat ke bawah.
Contoh: =INT(7.9) → 7
#019
TRUNC
=TRUNC(angka;desimal)
Memotong desimal tanpa pembulatan.
Contoh: =TRUNC(9.99;0) → 9
#020
SUBTOTAL
=SUBTOTAL(no_fungsi;range)
Kalkulasi pada data yang difilter (SUM, AVG, COUNT, dll.) tanpa menghitung baris tersembunyi.
Contoh: =SUBTOTAL(9;D2:D100) — SUM filtered

Logika & Kondisi

LOGIC
Pengambilan keputusan otomatis berdasarkan kondisi — sangat vital untuk laporan manajemen dan sistem penilaian.
#021
IF
=IF(kondisi;jika_benar;jika_salah)
Rumus kondisional paling dasar — evaluasi benar/salah.
Contoh: =IF(B2>=70;"Lulus";"Tidak Lulus")
#022
IFS
=IFS(kond1;hasil1;kond2;hasil2; ...)
Evaluasi banyak kondisi berurutan tanpa IF bertingkat.
Contoh: =IFS(A2>=90;"A";A2>=80;"B";A2>=70;"C";TRUE;"D")
#023
AND
=AND(kondisi1;kondisi2; ...)
Benar hanya jika SEMUA kondisi terpenuhi.
Contoh: =AND(B2>=70;C2="Hadir")
#024
OR
=OR(kondisi1;kondisi2; ...)
Benar jika SALAH SATU kondisi terpenuhi.
Contoh: =OR(B2="Manager";B2="Director")
#025
NOT
=NOT(kondisi)
Membalik nilai logika (TRUE jadi FALSE dan sebaliknya).
Contoh: =NOT(ISBLANK(A2))
#026
IFERROR
=IFERROR(nilai;jika_error)
Menampilkan nilai alternatif jika rumus menghasilkan error.
Contoh: =IFERROR(VLOOKUP(A2;data;2;0);"Tidak Ditemukan")
#027
IFNA
=IFNA(nilai;jika_NA)
Tangani hanya error #N/A (lebih spesifik dari IFERROR).
Contoh: =IFNA(VLOOKUP(A2;tabel;3;0);"–")
#028
SWITCH
=SWITCH(ekspresi;nilai1;hasil1; ...)
Cocokkan nilai ke daftar kasus seperti switch-case di pemrograman.
Contoh: =SWITCH(A2;1;"Jan";2;"Feb";3;"Mar";"Lainnya")
#029
XOR
=XOR(kondisi1;kondisi2)
TRUE jika tepat SATU kondisi yang benar (exclusive OR).
Contoh: =XOR(A2>10;B2>10)

Teks & String

TEXT
Manipulasi teks untuk pengolahan data, pembuatan laporan, dan pembersihan data kotor (data cleaning).
#030
CONCATENATE / &
=CONCATENATE(teks1;teks2) atau =A1&B1
Menggabungkan dua atau lebih string teks menjadi satu.
Contoh: =A2&" "&B2 → "Budi Santoso"
#031
TEXTJOIN
=TEXTJOIN(pemisah;abaikan_kosong;teks1; ...)
Gabungkan banyak teks dengan pemisah, bisa skip sel kosong.
Contoh: =TEXTJOIN(", ";TRUE;A2:A10)
#032
LEFT
=LEFT(teks;n_karakter)
Ambil sejumlah karakter dari kiri string.
Contoh: =LEFT("Jakarta";3) → "Jak"
#033
RIGHT
=RIGHT(teks;n_karakter)
Ambil sejumlah karakter dari kanan string.
Contoh: =RIGHT("ID-2024";4) → "2024"
#034
MID
=MID(teks;mulai;panjang)
Ambil karakter dari posisi tengah string.
Contoh: =MID("Komputer";4;4) → "pute"
#035
LEN
=LEN(teks)
Menghitung jumlah karakter dalam sebuah teks.
Contoh: =LEN("Excel") → 5
#036
UPPER / LOWER / PROPER
=UPPER(teks) / =LOWER(teks) / =PROPER(teks)
Ubah teks ke huruf BESAR, kecil, atau Kapital Setiap Kata.
Contoh: =PROPER("budi santoso") → "Budi Santoso"
#037
TRIM
=TRIM(teks)
Hapus spasi berlebih di awal, akhir, dan tengah teks.
Contoh: =TRIM(" Data Kotor ")
#038
SUBSTITUTE
=SUBSTITUTE(teks;lama;baru)
Ganti teks tertentu dalam string dengan teks lain.
Contoh: =SUBSTITUTE(A2;"-";"/")
#039
FIND / SEARCH
=FIND(cari;dalam_teks;mulai)
Temukan posisi karakter/kata dalam teks. FIND case-sensitive, SEARCH tidak.
Contoh: =FIND("@";B2) — posisi @ di email
#040
TEXT
=TEXT(nilai;format)
Mengubah angka/tanggal menjadi teks berformat tertentu.
Contoh: =TEXT(A2;"Rp#.##0") → "Rp5.000"
#041
VALUE
=VALUE(teks)
Mengubah teks berupa angka menjadi nilai angka sesungguhnya.
Contoh: =VALUE("12345") → 12345
#042
REPT
=REPT(teks;kali)
Mengulang teks sebanyak n kali. Bisa buat progress bar sederhana.
Contoh: =REPT("★";A2) — rating bintang

Lookup & Referensi

LOOKUP
Mencari dan mengambil data dari tabel lain — fondasi pembuatan database & laporan otomatis.
#043
VLOOKUP
=VLOOKUP(nilai;tabel;kolom;0)
Cari nilai di kolom pertama tabel, ambil data kolom lain di baris yang sama. Argumen ke-4: 0=tepat, 1=perkiraan.
Contoh: =VLOOKUP(A2;TabelProduk;3;0)
#044
HLOOKUP
=HLOOKUP(nilai;tabel;baris;0)
Sama seperti VLOOKUP tapi mencari secara horizontal (baris pertama).
Contoh: =HLOOKUP("Q3";TabelKuartal;2;0)
#045
XLOOKUP
=XLOOKUP(cari;range_cari;range_hasil;not_found)
Penerus modern VLOOKUP — lebih fleksibel, bisa cari ke kiri, tidak perlu nomor kolom.
Contoh: =XLOOKUP(A2;B:B;D:D;"N/A")
#046
INDEX
=INDEX(array;baris;kolom)
Ambil nilai dari posisi baris & kolom tertentu dalam range.
Contoh: =INDEX(B2:D10;3;2)
#047
MATCH
=MATCH(nilai;range;0)
Mengembalikan posisi (nomor urut) suatu nilai dalam range.
Contoh: =MATCH("Budi";A2:A100;0)
#048
INDEX + MATCH
=INDEX(kolom_hasil;MATCH(nilai;kolom_cari;0))
Kombinasi paling powerful — lebih fleksibel dari VLOOKUP, bisa cari ke segala arah.
Contoh: =INDEX(C:C;MATCH(A2;B:B;0))
#049
CHOOSE
=CHOOSE(indeks;val1;val2; ...)
Pilih nilai dari daftar berdasarkan nomor indeks.
Contoh: =CHOOSE(A2;"Jan";"Feb";"Mar")
#050
OFFSET
=OFFSET(referensi;baris;kolom;tinggi;lebar)
Menggeser referensi sel sejauh n baris/kolom. Berguna untuk range dinamis.
Contoh: =SUM(OFFSET(A1;0;0;COUNTA(A:A);1))
#051
INDIRECT
=INDIRECT(ref_teks)
Membuat referensi sel dari teks — referensi dinamis berubah saat teks berubah.
Contoh: =SUM(INDIRECT("Sheet"&A1&"!B:B"))
#052
TRANSPOSE
=TRANSPOSE(array)
Mengubah baris menjadi kolom dan sebaliknya (rotasi data).
Contoh: =TRANSPOSE(A1:D1) → data kolom

Tanggal & Waktu

DATE
Kalkulasi tanggal untuk laporan bulanan, penghitungan umur aset, deadline, dan jadwal proyek.
#053
TODAY
=TODAY()
Mengembalikan tanggal hari ini (diperbarui otomatis setiap hari).
Contoh: =TODAY()-B2 → selisih hari dari tanggal B2
#054
NOW
=NOW()
Mengembalikan tanggal dan jam saat ini.
Contoh: =NOW() → 27/04/2026 14:35
#055
DATE
=DATE(tahun;bulan;hari)
Membuat nilai tanggal dari angka tahun, bulan, dan hari.
Contoh: =DATE(2026;4;1) → 01/04/2026
#056
DAY / MONTH / YEAR
=DAY(tanggal) / =MONTH(tanggal) / =YEAR(tanggal)
Ekstrak komponen hari, bulan, atau tahun dari sebuah tanggal.
Contoh: =YEAR(A2) → 2026
#057
DATEDIF
=DATEDIF(mulai;akhir;"Y"/"M"/"D")
Hitung selisih antara dua tanggal dalam tahun, bulan, atau hari.
Contoh: =DATEDIF(B2;TODAY();"Y") → usia karyawan
#058
NETWORKDAYS
=NETWORKDAYS(mulai;akhir;hari_libur)
Hitung jumlah hari kerja antara dua tanggal (ekskl. Sabtu/Minggu/libur).
Contoh: =NETWORKDAYS(B2;C2;F2:F10)
#059
WORKDAY
=WORKDAY(mulai;hari_kerja;libur)
Hitung tanggal setelah n hari kerja dari suatu tanggal.
Contoh: =WORKDAY(TODAY();14) → deadline 2 minggu kerja
#060
EOMONTH
=EOMONTH(tanggal;bulan)
Tanggal akhir bulan, n bulan setelah/sebelum tanggal tertentu.
Contoh: =EOMONTH(TODAY();0) → akhir bulan ini
#061
WEEKDAY
=WEEKDAY(tanggal;tipe)
Mengembalikan angka hari dalam seminggu (1=Senin dst).
Contoh: =WEEKDAY(TODAY();2) → 1=Senin
#062
WEEKNUM
=WEEKNUM(tanggal;tipe)
Nomor minggu dalam setahun untuk sebuah tanggal.
Contoh: =WEEKNUM(TODAY()) → minggu ke-17
#063
HOUR / MINUTE / SECOND
=HOUR(waktu) / =MINUTE(waktu)
Ekstrak jam, menit, atau detik dari nilai waktu.
Contoh: =HOUR(B2) → 14 (pukul 14:30)

Statistik & Analisis Data

STAT
Analisis statistik untuk riset, laporan akademik, evaluasi kinerja, dan riset pasar ekonomi.
#064
MAX / MIN
=MAX(range) / =MIN(range)
Nilai terbesar atau terkecil dalam sekumpulan data.
Contoh: =MAX(B2:B100) — penjualan tertinggi
#065
LARGE / SMALL
=LARGE(range;k)
Nilai terbesar/terkecil ke-k dari sekumpulan data.
Contoh: =LARGE(B2:B50;3) → nilai terbesar ke-3
#066
MEDIAN
=MEDIAN(angka1;angka2; ...)
Nilai tengah dari sekumpulan data yang diurutkan.
Contoh: =MEDIAN(C2:C50)
#067
MODE.SNGL
=MODE.SNGL(angka1;angka2; ...)
Nilai yang paling sering muncul (modus) dalam data.
Contoh: =MODE.SNGL(B2:B100)
#068
STDEV.S / STDEV.P
=STDEV.S(range)
Standar deviasi dari sampel (S) atau populasi (P). Ukuran sebaran data.
Contoh: =STDEV.S(C2:C100)
#069
VAR.S
=VAR.S(range)
Varians dari sampel data. Kuadrat dari standar deviasi.
Contoh: =VAR.S(B2:B50)
#070
RANK.EQ
=RANK.EQ(angka;range;0)
Peringkat sebuah angka dalam daftar. 0=urutan besar ke kecil.
Contoh: =RANK.EQ(B2;$B$2:$B$50;0)
#071
PERCENTILE.INC
=PERCENTILE.INC(range;k)
Nilai pada persentil ke-k dari sekumpulan data (0 sampai 1).
Contoh: =PERCENTILE.INC(B2:B100;0.9) → persentil ke-90
#072
CORREL
=CORREL(array1;array2)
Koefisien korelasi Pearson antara dua rangkaian data (-1 hingga 1).
Contoh: =CORREL(B2:B100;C2:C100)
#073
FORECAST.LINEAR
=FORECAST.LINEAR(x;y_known;x_known)
Prediksi nilai berdasarkan tren linear (regresi sederhana).
Contoh: =FORECAST.LINEAR(13;B2:B12;A2:A12)
#074
FREQUENCY
=FREQUENCY(data;bins)
Distribusi frekuensi — berapa data masuk tiap interval (array formula).
Contoh: =FREQUENCY(B2:B100;{60;70;80;90})

Keuangan & Ekonomi

FINANCE
Rumus keuangan untuk analisis investasi, kalkulasi pinjaman, arus kas, dan laporan keuangan bisnis.
#075
PMT
=PMT(rate;nper;pv)
Hitung cicilan tetap pinjaman/kredit per periode (angsuran bulanan).
Contoh: =PMT(6%/12;60;-100000000) — cicilan KPR 100jt, 5 tahun, 6%/tahun
#076
PV
=PV(rate;nper;pmt;fv)
Present Value — nilai sekarang dari arus kas di masa depan.
Contoh: =PV(8%/12;36;-2000000)
#077
FV
=FV(rate;nper;pmt;pv)
Future Value — nilai investasi di masa depan dengan bunga majemuk.
Contoh: =FV(5%/12;120;-500000;0) — tabungan 10 tahun
#078
NPV
=NPV(rate;nilai1;nilai2; ...)
Net Present Value dari investasi — dasar analisis kelayakan proyek.
Contoh: =NPV(10%;C2:C6)-B1 — NPV minus investasi awal
#079
IRR
=IRR(values;perkiraan)
Internal Rate of Return — tingkat pengembalian internal suatu investasi.
Contoh: =IRR(B1:B6) — IRR dari arus kas proyek
#080
RATE
=RATE(nper;pmt;pv;fv)
Hitung suku bunga per periode dari suatu pinjaman atau investasi.
Contoh: =RATE(60;-2000000;100000000)*12
#081
NPER
=NPER(rate;pmt;pv)
Jumlah periode yang dibutuhkan untuk melunasi pinjaman atau mencapai target.
Contoh: =NPER(6%/12;-2000000;100000000)
#082
IPMT
=IPMT(rate;per;nper;pv)
Komponen bunga dari cicilan pinjaman pada periode tertentu.
Contoh: =IPMT(6%/12;1;60;-100000000)
#083
PPMT
=PPMT(rate;per;nper;pv)
Komponen pokok dari cicilan pinjaman pada periode tertentu.
Contoh: =PPMT(6%/12;1;60;-100000000)
#084
SLN
=SLN(cost;salvage;life)
Depresiasi garis lurus (Straight-Line) per periode untuk aset.
Contoh: =SLN(50000000;5000000;5) — depresiasi mesin 5 tahun
#085
DB
=DB(cost;salvage;life;period)
Depresiasi metode saldo menurun (Declining Balance) per periode.
Contoh: =DB(50000000;5000000;5;1)

Informasi, Database & Array

DB / INFO
Rumus pemeriksaan data, fungsi database, dan array dinamis untuk analisis data tingkat lanjut.
#086
ISBLANK
=ISBLANK(nilai)
Memeriksa apakah sebuah sel kosong (TRUE/FALSE).
Contoh: =IF(ISBLANK(B2);"Kosong";"Terisi")
#087
ISNUMBER / ISTEXT
=ISNUMBER(nilai) / =ISTEXT(nilai)
Cek apakah sel berisi angka atau teks. Berguna untuk validasi data.
Contoh: =IF(ISNUMBER(A2);"Angka";"Bukan Angka")
#088
ISERROR / ISERR
=ISERROR(nilai)
Cek apakah sel mengandung error apapun.
Contoh: =IF(ISERROR(A2/B2);0;A2/B2)
#089
CELL
=CELL("info_type";referensi)
Ambil informasi tentang sel: format, alamat, lebar kolom, dll.
Contoh: =CELL("address";A1) → "$A$1"
#090
DSUM
=DSUM(database;field;kriteria)
Jumlahkan field dalam database berdasarkan kriteria di range terpisah.
Contoh: =DSUM(A1:D100;"Penjualan";F1:F2)
#091
DCOUNT / DAVERAGE
=DCOUNT(database;field;kriteria)
Hitung/rata-rata field dalam database berdasarkan kriteria kompleks.
Contoh: =DAVERAGE(A1:D50;"Gaji";H1:H2)
#092
UNIQUE
=UNIQUE(array;by_col;exactly_once)
Keluarkan daftar nilai unik dari range (Excel 365/2019+). Hasil otomatis tumpah ke sel bawah.
Contoh: =UNIQUE(B2:B100) — daftar kota unik
#093
SORT / SORTBY
=SORT(array;kolom;urutan)
Urutkan array/range secara dinamis tanpa mengubah data asli.
Contoh: =SORT(A2:C100;3;-1) — urutkan kolom 3 menurun
#094
FILTER
=FILTER(array;termasuk;jika_kosong)
Filter data secara dinamis berdasarkan kondisi — hasil otomatis diperbarui.
Contoh: =FILTER(A2:D100;C2:C100="Jakarta";"Tidak ada")
#095
SEQUENCE
=SEQUENCE(baris;kolom;mulai;langkah)
Buat urutan angka otomatis dalam array (nomor urut, tahun, dll.).
Contoh: =SEQUENCE(12;1;2020;1) → 2020 s.d. 2031
#096
LET
=LET(nama1;nilai1; ...;kalkulasi)
Definisikan variabel dalam rumus untuk formula lebih bersih dan efisien.
Contoh: =LET(x;B2-C2;y;D2/E2;x*y)
#097
LAMBDA
=LAMBDA(param;kalkulasi)
Buat fungsi kustom sendiri yang bisa dipakai ulang (Excel 365+).
Contoh: =LAMBDA(x;x^2+2*x+1) — fungsi kuadrat
#098
ISNUMBER + SEARCH
=ISNUMBER(SEARCH("kata";sel))
Cek apakah suatu kata/teks terkandung dalam sel (teknik contains).
Contoh: =ISNUMBER(SEARCH("Manager";B2))
#099
MMULT
=MMULT(array1;array2)
Perkalian matriks — berguna untuk kalkulasi linear algebra dan ekonometri.
Contoh: =MMULT(A1:B2;D1:E2)
#100
GETPIVOTDATA
=GETPIVOTDATA("field";pivot_table;field1;item1)
Ambil data spesifik dari PivotTable berdasarkan field dan item tertentu.
Contoh: =GETPIVOTDATA("Penjualan";A3;"Wilayah";"Jakarta")
#101
ARRAYFORMULA / CTRL+SHIFT+ENTER
{ =rumus_biasa } (tekan Ctrl+Shift+Enter)
Jalankan rumus pada seluruh array sekaligus — satu rumus untuk banyak baris.
Contoh: {=SUM(B2:B10*C2:C10)} — total harga×qty
#102
HYPERLINK
=HYPERLINK(url;teks_tayang)
Buat tautan klik di dalam sel — menuju URL web atau lokasi lain dalam workbook.
Contoh: =HYPERLINK("https://example.com";"Kunjungi")
#103
ROW / COLUMN
=ROW(referensi) / =COLUMN(referensi)
Kembalikan nomor baris atau kolom dari referensi sel.
Contoh: =ROW()-1 — nomor urut mulai dari 1
